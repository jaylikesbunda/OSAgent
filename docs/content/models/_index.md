OSA talks to 200+ model providers through one config surface:

1. **[Providers]({{< relref "providers.md" >}})** — OpenRouter, OpenAI, Anthropic, Google, Ollama, Bedrock, and more.
2. **[OAuth login]({{< relref "oauth.md" >}})** — sign in with OpenAI, Anthropic, Google, GitHub Copilot, Qwen, or Chutes instead of pasting API keys.

Local-first tip: point OSA at a local Ollama instance and it runs entirely off-grid.
